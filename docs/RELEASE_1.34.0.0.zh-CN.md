# AI Weather Advanced 1.34.0.0

发布日期：2026-09-16。基于 Advanced 1.33.0.0，并合入上游至 1.15.5.0。

## 本次更新

- Gemini 免费模型池增加 `gemini-3.8-flash`，默认排在 `gemini-3.7-flash` 前面、两个 Flash-Lite 模型后面；保留已有自定义模型的相对顺序。
- 修正模型池混合失败的汇总提示：某个模型达到 RPD、其他模型返回参数或其他错误时，不再一概显示“所有模型额度耗尽，等待明天”。只有所有模型都处于限额暂停状态时，才显示池级恢复时间；同时显示逐模型结果。
- 保持每个模型独立的限额状态机。一个模型 RPD 用尽后继续尝试后续可用模型；默认完整遍历两轮。
- 融合上游 Gemini 请求参数兼容、截断输出检测和严格结果解析。无效回答不会被伪装成云量 50% 的成功在线结果；继续沿用明确标注的本地 ONNX 回退。
- 普通 Gemini 仍为一次检查只请求一个选定模型，不进行跨模型轮询或同轮重试。
- 增加提供方测试、连续失败诊断及重复图像诊断。提供方测试只有在用户主动点击时才请求在线 API，不改变安全监视器结论或写入训练样本。
- 预览延迟到控件已加载且可见后启动；意外播放中断按有上限的间隔重连。保留每个终端内部预览与分析共用 RTSP 会话的设计。
- 样本检查器中教师云量、学生云量、差值列按实际数字排序，缺失值保持为空，不再按百分数字符串排序。

## 验证范围与限制

- 非在线单元/集成测试共 61 项，涵盖单模型 RPD 后继续、混合错误汇总、全池 RPD、下一轮请求参数兼容及普通 Gemini 单次请求策略。
- 另有数据集与 RTSP 策略 smoke 测试，包含本次数值排序回归测试。
- 上述验证不消耗真实 API 额度，不代表已复现朋友电脑的具体限额故障或完成朋友台站的摄像头断线测试。
- 保持现有安全状态规则、主从接管机制及站点训练 ONNX 模型，不因本次发布放宽安全条件。

## 安装与打包

- N.I.N.A. 3.x / Windows x64 插件包，不是完整 N.I.N.A. 安装包。
- 仅保留 Windows x64 原生运行库及插件依赖、内置推理模型；不打包其他操作系统或 x86/ARM64 库。
- 打包上限为解压后 260 MiB、压缩包 180 MiB，超限阻止发布。
- 不包含本机配置、API 密钥、摄像头凭据、共享令牌、数据集、训练环境或检查点。
- 安装时退出 N.I.N.A.，先将旧插件目录备份到插件扫描目录之外，再替换 `AI Weather` 目录。用户配置及 `NINA/AIWeather` 数据目录不受替换影响。

上游融合细节见 [2026-09-16 融合说明](UPSTREAM_MERGE_20260916.zh-CN.md)。
