# AI Weather - N.I.N.A. 全天相机天气监视器

[English](README.md) | 简体中文

AI Weather 是一款面向 [N.I.N.A.](https://nighttime-imaging.eu/)（Nighttime Imaging 'N' Astronomy）的全天相机天气监视与安全设备插件。它从 RTSP、HTTP 或本地图片目录取得天空图像，通过在线视觉模型、OpenAI 兼容服务或本地算法判断云量、降雨、雾气等状况，并把最终结果作为 N.I.N.A. Safety Monitor 的 `Safe / Unsafe` 状态提供给序列。

> [!IMPORTANT]
> 本仓库是基于 [michelebergo/nina.plugin.aiweather](https://github.com/michelebergo/nina.plugin.aiweather) 持续开发的社区高级分支，保留原作者署名与 MIT 许可证。这里的高级功能可能尚未进入上游稳定版。

> [!WARNING]
> 图像识别可能误判，网络服务也可能限流或中断。本插件采用保守的失效安全策略，但它不能替代可靠的雨量、湿度、云量、屋顶联锁和紧急关盖等硬件保护。无人值守天文台应使用彼此独立的多重安全措施。

## 这个高级分支增加了什么

除上游已有的全天相机识别、Safety Monitor、三种取图方式和多种 AI 服务外，当前 `advanced` 分支还包含：

- **完整简体中文界面**：跟随 N.I.N.A. 当前语言自动切换；数据文件中的稳定机器值保持不变。
- **仅夜间分析**：可按太阳高度角限制工作时段。白天不抓图、不调用本地或在线模型、不写数据集，并直接向 N.I.N.A. 报告 `Unsafe`。
- **教师—学生数据集采集**：用成功的在线视觉模型结果作为教师标签，同时保存同一帧的本地影子算法结果，为将来训练站点专属模型积累数据。
- **内置标签检查器**：无需逐层打开分片目录，即可搜索、筛选、浏览图片，对教师标签执行接受、人工修正、拒绝或重置复核等操作。
- **按检查次数采样**：每完成 `N` 次成功的在线天气检查保存一个周期样本；有意义的异常或分歧样本仍可独立采集。
- **可控的数据量**：支持等比例降采样、JPEG 质量、内容寻址、近重复过滤、数据集容量和磁盘剩余空间保护。
- **更完整的失效安全逻辑**：过期结果、相机或模型失败、可选外部 ASCOM 安全设备异常、白天停用或无法取得太阳高度时都不会继续沿用旧的 `Safe`。
- **高级序列符号**：在 N.I.N.A. 3.3 及以上版本中发布 `Cloud`、`Confidence`、`Condition`、`Rain`、`Fog` 和 `Safe`。

教师—学生数据集的设计、字段、隐私边界和后续训练路线详见 [设计文档](docs/TEACHER_STUDENT_DATASET_DESIGN.zh-CN.md)。

## 主要能力

### 天气识别

插件可从一张全天图中输出：

- 云量百分比（0–100%）；
- 天气类别：晴朗、局部多云、大部多云、阴天、下雨或有雾；
- 雨滴、雨痕、镜头凝露和雾气迹象；
- 模型置信度；
- 对当前画面的自然语言说明；
- 结合高/低阈值回差后的最终观测安全状态。

### 三种图像来源

| 模式 | 适用设备 | 工作方式 |
|---|---|---|
| **RTSP 视频流** | 网络全天相机、监控摄像机 | 连接实时 RTSP 流并显示预览；OpenCV 不兼容时可回退到 LibVLC。 |
| **HTTP 图片** | 能提供快照地址的相机或远程服务 | 每次检查下载一张 HTTP/HTTPS 图片，支持 Basic 身份验证。 |
| **文件夹监视** | AllSky、SharpCap、ASI Studio 等 | 读取指定目录中最新的 JPG、PNG、BMP、TIFF 或 FITS 图片。 |

RTSP 用户名和密码会在写入 URL 前进行百分号编码，以兼容密码中的 `@`、`:`、`/` 等字符。

### AI 提供方

| 提供方 | 特点 | 要求 |
|---|---|---|
| **Google Gemini** | 在线视觉模型；模型列表从 API 动态发现 | Gemini API 密钥 |
| **OpenAI** | 在线视觉模型；动态筛选支持图像的模型 | OpenAI API 密钥 |
| **Anthropic Claude** | 在线视觉模型 | Anthropic API 密钥 |
| **Ollama / 自定义服务** | 支持 Ollama、LM Studio、llama.cpp、LocalAI 等 OpenAI 兼容接口 | 本地或局域网服务地址 |
| **本地算法** | 完全离线、无需密钥、响应快 | 无 |

GitHub Models 服务已于 2026 年 7 月停止，保留的选项只会给出明确说明并回退到本地分析，不应再用于新配置。

在线模型超时、限流、返回格式错误或网络不可达时，插件会标明失败原因并回退到本地分析。**回退结果可以维持天气检查，但不会伪装成成功的在线教师标签。**

## 安全状态怎样得出

插件注册为 N.I.N.A. Safety Monitor。最终状态遵循保守原则：所有启用的安全条件都满足时才会报告 `Safe`。

| 情况 | 最终状态 | 说明 |
|---|---:|---|
| 太阳高度达到或高于设定上限 | `Unsafe` | 在抓图前暂停，因此不会消耗在线 API，也不会采集白天数据。 |
| 太阳高度门控已启用，但无法取得有效观测站坐标或太阳高度 | `Unsafe` | 失效时保持关闭，而不是猜测当前为夜间。 |
| 雨、雾或云量达到不安全阈值 | `Unsafe` | 云量使用高/低两个阈值形成回差，避免在临界值附近反复跳变。 |
| 图像或分析连续失败，最近一次有效数据超过最大年龄 | `Unsafe` | 自动值为检查间隔的 3 倍，且不少于 10 分钟；也可手动设定。 |
| 启用了外部 ASCOM Safety Monitor，而外部设备未配置、断开或报告不安全 | `Unsafe` | 外部状态与图像识别结果执行逻辑与。 |
| 刚连接、重新连接，尚未完成第一次有效分析 | `Unsafe` | 不复用上一次会话的旧判断。 |
| 所有已启用条件均正常且天空判断安全 | `Safe` | 可供 N.I.N.A. 序列和插件符号使用。 |

断开 Safety Monitor 时，当前结论会被清除。可选状态文件和高级序列符号使用与 N.I.N.A. 完全相同的最终合并状态，不会各自重新计算。

## 仅夜间分析

如果全天相机固定使用夜间曝光参数，白天云层很容易大范围过曝。这类画面既浪费 API 请求，也会污染训练数据。可在插件设置中启用 **仅夜间分析**：

1. 打开 N.I.N.A. 的 **选项 → 插件 → AI Weather**。
2. 启用 **仅夜间分析**。
3. 设置太阳高度上限。默认建议为 `-6°`，即民用暮光结束后才开始工作。

常见参考值：

| 太阳高度 | 含义 | 适合场景 |
|---:|---|---|
| `0°` | 日落/日出 | 只排除太阳在地平线以上的时段 |
| `-6°` | 民用暮光 | 推荐起点，兼顾节省 API 与较早开始监视 |
| `-12°` | 航海暮光 | 相机需要更暗环境时使用 |
| `-18°` | 天文暮光 | 只在接近完整天文夜的时段运行 |

达到工作时段后，插件会自动恢复监视；不需要手动停止和重新连接。

## 教师—学生数据集

数据集功能默认关闭，必须主动启用。其目标是在正常天气监视的同时，低成本积累可审计、可人工复核的数据，为后续训练本地站点专属模型做准备。

```text
同一张全天图
    ├─ 在线视觉模型 ──> 教师结果 ──┐
    ├─ 本地影子算法 ──> 学生结果 ──┼─> 采样、去重、脱敏与原子写入
    └─ 天文上下文 ────> 太阳/月亮 ──┘
                                      └─> 标签检查器人工复核
```

### 什么样的结果能成为教师标签

只有同时满足以下条件的在线结果才可进入可训练数据：

- 在线请求真正成功，而不是本地回退；
- 返回内容能按约定结构解析并通过校验；
- 提供方、精确模型、提示词版本、耗时和来源均有记录；
- 图片和标签完整写入，且没有触发磁盘保护。

失败、格式无效或来源存疑的响应可以按设置进入隔离区，供排错参考，但不会混入正常训练集。

### 学生结果目前是什么

当前学生结果来自插件内置的本地启发式算法。它在在线教师成功时以 **影子模式** 运行，用来记录同帧差异，不会替换正在生效的在线安全判断。数据采集本身也不会自动训练或部署新模型；后续仍需经过人工清洗、划分数据集、训练、评估和安全验证。

### 当前默认采集参数

| 参数 | 默认值 | 含义 |
|---|---:|---|
| 每 `N` 次成功检查采样 | `1` | 每次成功的在线检查都具备周期采样资格；事件样本不受此比例限制。 |
| 数据集容量上限 | `20 GB` | 达到上限后停止新增，避免无限占用磁盘。 |
| 磁盘最小剩余空间 | `5 GB` | 低于该值时自动停止写入。 |
| 图片等比例降采样 | `50%` | 宽和高都缩小为原图的一半，保持原始宽高比。 |
| JPEG 质量 | `85` | 在细节、训练价值和磁盘占用之间折中。 |
| 云量分歧事件阈值 | `20%` | 教师与学生云量差达到该值时优先保留为事件样本。 |
| 相似图片过滤强度 | `4` | 使用 64 位平均哈希；两帧差异位数不超过 4 时视为近重复。数值越大，过滤越强。 |
| 保存教师原始 JSON | 关闭 | 开启后也会先脱敏；通常不需要保存。 |
| 保留异常响应到隔离区 | 开启 | 便于追踪无效或失败响应，但不作为正常教师标签。 |

“相似图片过滤强度”可设置为 `0–64`。`0` 只过滤哈希完全相同的画面；数值越大，越多相似画面会被跳过。全天相机连续帧通常建议从 `4` 开始，超过 `8` 往往会过度丢弃缓慢变化但仍有价值的天空状态。

### 标签检查器

内置检查器把深层分片目录中的样本汇总到一个可读界面中，支持：

- 按文本和复核状态搜索、筛选；
- 图片按窗口完整缩放显示，不裁切填充；
- 并排查看教师天气、云量、置信度，学生结果、差值和采样原因；
- **接受教师标签**：保留教师结论并标记已审核；
- **保存人工修正**：另存独立人工标签，不覆盖原始教师标签；
- **拒绝样本**：排除不适合训练的画面；
- **重置为未复核**：撤销当前复核状态；
- 记录递增修订号和只追加的月度审计日志。

人工复核保存为独立 sidecar 文件。原始教师标签保持不可变，并在加载复核结果时校验 SHA-256，便于追溯标签从哪里来、被谁以何种方式处理。

### 隐私与磁盘安全

数据集记录会排除观测站经纬度，并对 API 密钥、令牌、密码、带认证信息的 RTSP 地址以及常见自由文本凭据进行脱敏。图片和标签只写入用户配置的本地目录，不会由数据集模块自动上传。

写入使用有界后台队列、单写入器和原子替换；意外中断后可根据索引和 JSONL 记录恢复。达到容量上限、磁盘空间不足或路径不可用时，采集会安全停止，不影响正在进行的天气判断。

## 安装

### 上游稳定版

如果只需要上游发布的稳定功能，可从 [上游 Releases](https://github.com/michelebergo/nina.plugin.aiweather/releases) 下载并按 N.I.N.A. 插件安装方式部署。请注意：上游发布包不一定包含本页介绍的高级分支功能。

### 当前高级分支

本仓库的高级功能目前以 `advanced` 分支源码为准。开发者可执行：

```powershell
git clone https://github.com/sedirk/nina.plugin.aiweather-advanced.git
cd nina.plugin.aiweather-advanced
git switch advanced
dotnet restore
dotnet build AIWeather.sln -c Release
```

要求：

- Windows 10/11；
- .NET 8 SDK；
- N.I.N.A. 3.0 或更高版本；
- N.I.N.A. 安装在常见位置，或在项目中修正对应的程序集引用路径。

数据集与本地化的独立冒烟测试可通过以下命令运行：

```powershell
dotnet run --project tests/AIWeather.DatasetSmoke/AIWeather.DatasetSmoke.csproj -c Release
```

如果使用本地 OpenAI 兼容服务，请先单独确认服务能够接收图像，并在插件中刷新模型列表、选择视觉模型后再测试 API。

## 基本配置

1. 在 **选项 → 插件 → AI Weather** 中选择 RTSP、HTTP 图片或文件夹监视，并填写对应地址。
2. 选择 AI 提供方。初次使用在线服务时，先输入密钥并执行连接测试。
3. 设置检查间隔、云量不安全高阈值和恢复安全低阈值。
4. 无人值守站建议启用仅夜间分析，并确认 N.I.N.A. 中的观测站经纬度正确。
5. 如有独立雨量或环境设备，可启用外部 ASCOM Safety Monitor 并选择设备。
6. 前往 **设备 → Safety Monitor**，选择 **All Sky Camera Safety Monitor** 并连接。
7. 打开 **成像 → AI Weather**，确认实时画面、活动日志、数据年龄和状态原因均正常。
8. 在实拍序列前，分别模拟相机断流、API 失败、外部设备断开和白天门控，确认系统都能进入预期的 `Unsafe`。

### 场地说明

“场地说明”会附加到所有在线模型的分析提示中，可描述本地画面的固定特征，例如：

- 鱼眼镜头上方的屋檐或固定遮挡；
- 城市光害会把云层照成橙色；
- 圆顶反光或地平线附近的永久亮区；
- 水滴在本相机上的典型形态。

它只帮助模型理解画面，不会修改云量阈值、安全规则或结构化输出格式。不要在场地说明中写入密码、密钥或精确地址。

## 高级序列与外部集成

N.I.N.A. 3.3 及以上版本会在高级序列符号侧栏中显示 `AIWeather` 分类：

| 符号 | 类型 | 含义 |
|---|---|---|
| `AIWeather.Cloud` | 数字 | 云量百分比 |
| `AIWeather.Confidence` | 数字 | 模型置信度百分比 |
| `AIWeather.Condition` | 文本 | 当前天气类别 |
| `AIWeather.Rain` | 布尔 | 是否检测到降雨 |
| `AIWeather.Fog` | 布尔 | 是否检测到雾气 |
| `AIWeather.Safe` | 布尔 | N.I.N.A. 实际使用的最终合并安全状态 |

插件还提供 **AI Weather - Start Monitoring** 和 **AI Weather - Stop Monitoring** 两个高级序列指令。断开监视器时符号会被清空，避免序列继续读取旧值。

可选的安全状态文件只写入 `Safe` 或 `Unsafe`，可供 ASCOM Generic File SafetyMonitor 或外部脚本读取。

## 已知边界

- 本地算法是基于颜色、亮度、对比度、昼夜状态和鱼眼区域等特征的启发式基线，对不同相机、曝光和场地的泛化能力有限。
- 在线模型的结果会受模型版本、限流、服务可用性、画面曝光和提示词影响；选择模型后应使用本地真实天气样本验证。
- 太阳高度门控依赖 N.I.N.A. 中正确的观测站坐标和时间。
- 标签检查器用于整理标签，不会替用户完成模型训练，也不会自动把人工修正用于当前安全判断。
- 全天图无法保证探测到传感器盲区之外的降雨、结露、强风或机械故障。
